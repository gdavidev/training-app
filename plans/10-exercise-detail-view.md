# Exercise Detail View

**Priority:** Feature  
**Date reported:** 21/04/2026

## Tasks

- [ ] Create a dedicated exercise detail screen accessible from the exercise list and history
- [ ] Display a load progression graph (weight/reps over time per set across sessions)
- [ ] Show exercise frequency (how often it appears in completed workouts)
- [ ] Show how many times the exercise was skipped across sessions
- [ ] Add a suggestions section with contextual tips (e.g. increase weight, deload, try variation) based on recent performance trends

## Context

Users need a way to inspect individual exercise performance over time without relying on the general history view. The graph and frequency data already exist in the session records and can be aggregated per exercise. Suggestions should be rule-based initially (e.g. "you've completed all sets at this weight for 3 sessions — consider increasing").
